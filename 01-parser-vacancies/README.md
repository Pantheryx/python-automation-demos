# Вакансии в Excel

Собирает вакансии с открытого API портала «Работа России» и делает книгу Excel со сводкой по зарплатам, регионам и компаниям.

## Что нужно

- Python 3.11+
- 2 минуты на установку

## Установка

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```powershell
python main.py --text python --limit 400 --out out/report.xlsx
```

Несколько запросов через запятую:

```powershell
python main.py --text "python,django,fastapi" --limit 400
```

## Результат

`out/report.xlsx`, четыре части:

- **Данные** — вакансия, компания, регион, зарплата от/до/средняя, занятость, ссылка;
- **Сводка** — медиана, средняя, минимум и максимум, топ-10 регионов и компаний, график;
- **Ошибки** — что пропущено и почему (дубли, пустые записи);
- **Инструкция** — как обновить отчёт.

## Ограничения

- API отдаёт не больше 100 записей на один запрос и не поддерживает постраничный обход при поиске, поэтому полная выборка собирается несколькими запросами с удалением дублей.
- Источник — только открытые данные, официальный API. Обхода защиты нет.
- Если сайт изменит формат ответа, потребуется правка разбора.

python -m unittest discover -s tests -v
