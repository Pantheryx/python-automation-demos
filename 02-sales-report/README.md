# Отчёт по продажам из трёх выгрузок

Превращает три «грязных» CSV в один Excel-отчёт с формулами и листом ошибок.

## Что нужно

- Python 3.11+
- `openpyxl`

## Запуск

```powershell
pip install openpyxl
python report.py
```

Демо-данные создаются отдельно:

```powershell
python make_demo_data.py
```

## Результат

`output/report.xlsx`:

- **Данные** — 60 очищенных строк, таблица с фильтром;
- **Сводка** — выручка и средний чек по категориям, формулы `COUNTIF`/`SUMIF`, график;
- **Ошибки** — что не распознано: дубли, пустые строки, битые даты и суммы;
- **Инструкция** — как обновить отчёт за 3 шага.

## Что чистится

- даты в трёх форматах: `01.03.2026`, `2026-03-05`, `5 марта 2026`;
- суммы: `1 234,50`, `1234.5`, `1234 ₽`;
- дубли по ключу «дата + товар + сумма + клиент»;
- категории: `носки`, `НОСКИ`, `Носки` → `Носки`;
- пустые строки.

## Контроль

Скрипт печатает: строк на входе, на выходе, отброшено, выручка, средний чек. Если суммы не сходятся — причина в листе «Ошибки».

## Ограничения

- разделитель CSV — `;`, кодировка UTF-8;
- колонки фиксированные: `дата; товар; категория; количество; сумма; клиент`;
- для другого формата нужна правка маппинга.
